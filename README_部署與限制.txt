福氣安康 暖暖陪伴 V2.0 橫向壁掛與用藥鬧鐘版

1. 上傳 family_pwa 目錄內所有檔案至 HTTPS 網站。
2. 在平板瀏覽器開啟並加入主畫面，選擇橫向擺放。
3. 每次重啟後按「啟用鬧鐘聲音」，並在「家屬通知」測試。
4. 家屬通知管道及名單目前只提供設定，未連接 LINE/SMS/Web Push 發送端，絕不會實際傳訊。
5. 響鈴僅在頁面持續前景執行且音訊可用時有效；關屏、系統睡眠、斷電、瀏覽器關閉可能失效。重要用藥需獨立鬧鐘備援。
6. 沿用 warmfamily_v1 本機資料，更新前請先匯出備份。
7. 若要實際自動通知家屬，需新增 Supabase 等雲端排程、驗證、發送端金鑰與家屬綁定。

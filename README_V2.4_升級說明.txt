福氣安康 暖暖陪伴 V2.4
1. 天氣每10分鐘自動更新，取消手動按鈕與颱風資訊。
2. 用藥新增可選音效與自訂延後分鐘（1～180）。
3. sound 資料夾放入 MP3/WAV/OGG 後，編輯 sounds.json 登記檔名與顯示名稱；GitHub 上傳需包含整個 sound 資料夾。
4. 提醒畫面顯示藥名與服用說明；同一人同時刻的藥品合併列出，確認後一併記錄。
5. 延後時間從按下按鈕當下起算，且延後時間保存在本機。
6. 音訊需使用者點擊啟用；背景、鎖屏及系統休眠時仍無法保證響鈴。家屬通知仍未連線。
7. 請先匯出原有備份，再更新 GitHub Pages；保留舊 localStorage 資料。
